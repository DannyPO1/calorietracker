# CalorieTracker v6.2.12

Persoonlijke calorie- en voedingsregistratie voor iPhone/Safari. Gegevens worden lokaal opgeslagen; een account is niet nodig.

## Release notes — v6.2.12

### Dashboardiconen
- De eiwit- en koolhydraat/vet-iconen gebruiken nu een transparante achtergrond buiten de cirkel.
- De ongewenste vierkante donkere achtergrond is verwijderd.
- De bestaande mock-up-vorm en kleuren van de iconen zijn behouden.

### Voortgangsgrafiek
- De positie van het label **kg** is aangepast zodat het niet meer tegen de hoogste y-aswaarde aanloopt.
- Er is meer verticale ruimte gecreëerd tussen het eenheidslabel en de bovenste grafiekwaarde.

### Technisch
- Applicatieversie bijgewerkt naar **v6.2.12**.
- Service-workercache bijgewerkt naar **6.2.12**.

## Deployment
Upload `CalorieTracker-iPhone-v6.2.12.zip` naar de repository en commit de ZIP. De bestaande GitHub Actions-workflow installeert de release, maakt de releasecommit en tag `v6.2.12`.
