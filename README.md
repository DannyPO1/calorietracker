# CalorieTracker v6.2.8

Persoonlijke calorie- en voedingsregistratie voor iPhone/Safari. Gegevens worden lokaal opgeslagen; een account is niet nodig.

## Release notes — v6.2.8

### Dashboard
- De vier voedings-/dashboardiconen zijn visueel vernieuwd naar een modernere set: kippenpoot voor eiwit, tarwe voor koolhydraten/vet, doelwit voor dagdoel en lijst voor registraties.
- De iconen zijn groter en consistenter vormgegeven, met zachte kleurvlakken en subtiele diepte.
- De bestaande dark-theme dashboardstijl van v6.2.7 blijft behouden.

## Belangrijkste functionaliteit
- Dagelijkse calorie- en macronutriëntenregistratie.
- Eigen producten en recepten.
- Stuksgewicht voor producten wanneer dat logisch is.
- Barcode-scanner en productkoppeling.
- AI-voedingsscan met Gemini 3.1 Flash-Lite.
- Voedingsdatabase met standaardproducten en praktische porties.
- Voortgang, gewichtsontwikkeling en doelgewicht.
- Lokale opslag en migratie-/back-upfunctionaliteit.

## Deployment
De release wordt via de bestaande GitHub Actions-workflow geïnstalleerd wanneer `CalorieTracker-iPhone-v6.2.8.zip` naar de repository wordt geüpload en gecommit. De workflow maakt vervolgens de releasecommit en tag `v6.2.8`.
