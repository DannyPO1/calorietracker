# CalorieTracker v6.2.13

Persoonlijke calorie- en voedingsregistratie voor iPhone/Safari. Gegevens worden lokaal op dit apparaat opgeslagen; een account is niet nodig.

## Release notes — v6.2.13

### Producten en recepten kopiëren
- In het wijzigingsformulier van een eigen product is nu **Opslaan als nieuw product** beschikbaar.
- In het wijzigingsformulier van een recept is nu **Opslaan als nieuw recept** beschikbaar.
- De oorspronkelijke registratie blijft behouden; de gewijzigde gegevens worden onder een nieuwe naam opgeslagen.
- Als de gekozen naam al bestaat, vraagt de app om een unieke naam en voorkomt zo onbedoeld overschrijven.
- Bij productvarianten blijven beschikbare barcode- en merkgegevens behouden.

### Technisch
- Applicatieversie bijgewerkt naar **v6.2.13**.
- Service-workercache bijgewerkt naar **6.2.13**.

## Deployment
Upload `CalorieTracker-iPhone-v6.2.13.zip` naar de repository en commit de ZIP. De bestaande GitHub Actions-workflow installeert de release, maakt de releasecommit en tag `v6.2.13`.
